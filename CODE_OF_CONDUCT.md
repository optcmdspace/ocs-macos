# Code of Conduct

This project adopts version 2.1 of the Contributor Covenant. The full text is at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, give and accept constructive feedback. Behavior that excludes, demeans, or threatens others is not welcome here.

## Reporting

If you witness or experience behavior that violates this code, contact the maintainer privately at rodrigo@optcmd.space. Reports are kept confidential.

## Enforcement

The maintainer will review the report and take action proportional to the situation, which may include a private warning, a temporary ban from project spaces, or a permanent ban. Decisions are final.

## Scope

This code applies to all project spaces, including the repository, issues, pull requests, discussions, and any other channel hosted under this project.
